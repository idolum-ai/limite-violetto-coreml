# Independent pipeline benchmark decision review

The completed eight-worker benchmark passes its predeclared performance gate. I independently rehashed each worker result and score archive, checked all eight cohort/loader/runtime bindings, verified 32 of 32 requests disposed and each worker's 50 plain / 408 state / 458 GIL-release guarded calls, and recomputed all timing medians from 96 raw timed forwards. All 96 saved score vectors are raw-byte equal to the first baseline worker **and** to the 12 shared sites in the sealed historical Core ML pilot, whose source identity, fixture hash, and 719-token stream match this run. The machine-readable audit is `pipeline-independent-audit.json`.

Median decode reductions are 17.28%, 17.46%, and 18.10% for prefixes 32, 128, and 512; pooled reduction is 17.83%. Median prefill changes are +0.87%, +0.74%, and −5.76%. These satisfy the predefined at-least-10% decode and at-most-10% prefill-regression thresholds. The result supports an observed local CPU_ONLY speedup and exact scores for this fixed stream. It does not measure GPU execution or establish a device-wide speedup.

The run's own variability flag is material: prefix-32 decode reduction was 8.06% in round 0 and 20.12% in round 1, a 12.06-point spread. Prefix 128 also moved from 11.81% to 20.64%; prefix 512 was steadier. Host telemetry shows a switch from AC to battery between the two B workers in round 0; 1-minute load averages ranged from 4.36 to 5.94, with no thermal warning recorded. These observations do not identify the cause of variation. The original gate remained passed, and a single predeclared prefix-32-only ABBA confirmation was run to assess this concern.

That confirmation passed independently audited gates: all 16 measured score vectors were raw-byte equal to the first baseline worker and sealed historical pilot, all eight requests were disposed, and each worker had the expected 16 plain / 96 state / 112 GIL-release guarded calls. All eight before/after timing observations reported battery power and standard negative thermal/performance warning messages. Prefix-32 median decode time fell from 2.33641 to 1.81818 seconds (22.18% reduction); prefill fell from 6.66190 to 6.04409 seconds (9.27% reduction). The machine-readable audit is `prefix32-confirmation-independent-audit.json`. I recommend promoting this as the qualified **CPU_ONLY** conditional-score candidate with an observed local whole-pipeline speedup on the pinned stream, subject to the root's final source/cohort preservation check. The data do not establish a GPU speedup or a controlled-cache device-wide speedup.
