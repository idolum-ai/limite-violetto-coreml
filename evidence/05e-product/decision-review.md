# Independent 05e decision and next-experiment review

I recomputed each of the nine block/prefix medians from `benchmark-1/results.json`'s raw A/B timings. All 12 correctness, 24 excluded warmup, and 144 timed calls report exact outputs and eight states (180/180). Each cell has eight A and eight B observations. Variant median reductions range from **4.82% to 10.06%**; only block 1 at prefix 128 reaches the predeclared 10% threshold. Thus **1/9 passes**, the recorded `performance_gate_passed=false` and `no-go; do not integrate` decision are correct. This is a completed local negative result for the threshold, not evidence that the deleted products had zero cost. No hash, compilation, or inference was run for this review.

A **separate baseline-derived warm-only group-0 score-selector ablation is defensible**. For one real query at absolute position ≥32, `dynamic_queries.prepare` presents 32 query rows. `tiny_native_scores.scores` builds the short `_short_raw` path and the ordinary score path, then selects ordinary scores when rows ≥16. Removing the unreachable short path for this restricted domain tests another concrete graph-work hypothesis; the 05d component timing does not isolate that internal work, and Core ML may already eliminate or schedule it cheaply. Do not combine this change with the 05e value-product variant.

The safest gate is a copied qualified group-0 package plus a precise MIL data-flow audit: identify the four final short/full selectors from their consumers, prove that the ordinary-score input and all downstream arithmetic, paired value products, weights, state operations, and public interface remain unchanged, and prove which short-tree operations become unreachable or are removed. A constant-false selector alone is insufficient to claim work elimination unless the resulting compiled graph/measurement supports it. Preserve a strict harness contract of one real query and warm position 32–2047 before native prediction; outside that domain the short-score path is needed for source-CPU fidelity. Require exact `y`, `tap23_out`, and all eight post-call states against independently captured baseline fixtures at positions 32, 128, and 512 before timing. Predeclare a paired ABBA timing rule and retain the qualified compiled baseline separately. Any observed group-0 gain is local and does not qualify full-runtime routing or generation performance.
