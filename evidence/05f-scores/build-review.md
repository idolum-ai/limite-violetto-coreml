# Warm-score ablation build review

`scripts/build_warm_scores.py` is a side-by-side builder for a copied qualified group-0 package. It does not alter the sealed source or runtime. Its intended domain is one real query at warm absolute position 32–2047, enforced by the separate native harness before prediction; the package's broad public interface remains unchanged and is invalid for other query counts after this edit.

Static inspection of the pinned group-0 MIL program identified four final selectors: `scores_1`, `scores_3`, `scores_5`, and `scores`. Each has `a=short_scores*`, `b=full_scores*`, and `cond=less(rows*, 16)`; the ordinary-score input and selector output have identical tensor types. Each `rows*` is taken from `shape(query*)` at query axis 1. Each prepared query slices to `min(32, positions[-1]+1)`: the source MIL uses constant 32, the last input position, and constant 1. Therefore one query at position ≥32 gives 32 prepared rows and chooses the ordinary score input. The builder asserts the four selector signatures and sealed source candidate before editing.

The builder changes each final selector to an identity of its existing ordinary-score input, retaining the original output name/type. Global liveness from declared outputs and all state/zero-output operations identifies only newly dead ancestors of the short inputs and conditions. The static audit found **10,038** such pure operations, no matmul or state operations. All other surviving operation bytes, non-operation spec metadata, and package weight files must remain identical; source and copied-package files are inventoried. A separate attempt directory retains partial failure results. Syntax and an in-memory rewire/liveness/topological-reference check passed; no compilation or inference was run in this review.

Compilation acceptance and exact fresh-state replay of both outputs and all eight KV states at warm positions 32, 128, and 512 remain mandatory before timing. Removing source graph work does not establish that Core ML previously executed it or that the variant is faster. The 05e value-product ablation remains separate and is not part of this package.
