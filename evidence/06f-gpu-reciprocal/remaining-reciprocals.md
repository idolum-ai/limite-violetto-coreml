# Remaining group 0 reciprocal sites

The sealed 06d group 0 MIL has 433 `real_div` operations. Exactly 20 have a directly provable FP32 numerator of one: each numerator is `fill_like` of the same denominator with an FP32 scalar constant `1.0`. The first 06f candidate changes one of those sites, layer 0 post-attention normalization `var_5675` at original operation 9543. The other **19** are listed with original operation indices, SSA names, denominator producers, shapes, and immediate consumers in `remaining-reciprocals.json`. The graph/source ordering gives five such sites per layer: pre-attention norm, query norm, key norm, attention softmax, and post-attention norm. The 413 other `real_div` operations are outside this inventory; many belong to signed-even quantization and must not be treated as reciprocal-one sites. In particular, the four XSA normalization divisions (`vn_1`, `vn_3`, `vn_5`, `vn`) divide the value vector by a clamped L2 norm, so their numerators are not one.

The next site in execution order is layer 1 pre-attention normalization `var_7154` at original operation 12034. That makes it a narrow next diagnostic for the observed warm drift moving beyond layer 0, but the current evidence does not establish it as the cause. I recommend instrumenting its raw denominator and seed on the same captured input/state, then trying a **single-site** correction with CPU preservation and plain-versus-tapped endpoint/state controls. A 19-site cohort would obscure which correction changes the first differing cache and would mix norm denominators with softmax totals whose ranges may differ. Once individual denominator/seed behavior and the bounded `[0.5, 8]` guard are characterized, a guarded norm cohort could be evaluated separately from softmax sites.

This is a saved-graph inventory only. It does not establish GPU execution, denominator range coverage, one-ULP seed quality, or full-model fidelity at the remaining sites.
