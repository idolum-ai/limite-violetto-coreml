# Bounded reciprocal correction in group 0

The candidate starts from the frozen 06d signed-even-round group 0 package. It changes one MIL operation site: the existing `real_div` at operation 9543, formerly producing `var_5675`, now produces `reciprocal_seed`. The 144 operations exported by the externally seeded native C3b correction model are inserted immediately after it. Their internal SSA names and symbolic query dimensions are remapped, while their arithmetic, operation types, constants, and order are retained. Six subsequent guard operations select the original seed whenever the normalization denominator is below 0.5 or above 8.0; the selected output resumes the original `var_5675` name and descriptor. All 46,034 other source operations remain byte-identical, including state writes. The source package's weights and external inputs/outputs remain unchanged.

A second package has the identical operations and weights, with the twelve previously controlled normalization taps and a new `reciprocal_seed` output. Plain and tapped packages must be tested on the same effective input and restored state. The tapped clone is diagnostic only; equality of its original outputs and all eight states with the plain package is a mandatory control before interpreting a tap.

The externally seeded C3b component passed its bounded native arithmetic gate. Its standalone GPU seed did **not** reproduce the saved baseline, so neither that component result nor the static graft establishes in-model seed accuracy. The next native gate must compare the new `reciprocal_seed` with the saved original `var_5675`, preserve original CPU endpoints and states byte-for-byte, and test candidate GPU outputs on the identical captured inputs and states. The host proof covers the specified finite range and tested one-ULP seed cases; it is not an unrestricted reciprocal theorem for the full model. No performance or full-model fidelity conclusion follows from this group package.

`scripts/build_boundary_reciprocal_group.py --source-preflight` inspects saved protobufs and performs the complete rewrite in memory without creating a package or making a native prediction. A fresh `--attempt` copies the sealed package, writes separate plain and tapped models, records full file inventories, and optionally compiles them when root launches it. The builder refuses an occupied attempt and rechecks all frozen input hashes and source inventories.
